The matcher does not recurse on the C stack. Its caller-provided backtrack workspace uses
`depth * (capture_slots + 2) * sizeof(void *)` bytes. On a 32-bit target that is 16 bytes per
choice point with no user captures and 24 bytes with one capture.

The compiled bytecode for each pattern is additional flash data. For example:

  node tools/re_compile.js '\bfoo\b' word_test

emits the bytecode header, overall capture slots and the VM's search wrapper.

The first case-insensitive compilation builds a Unicode simple-fold reverse map in the host-side
JavaScript process. This affects compiler startup time and memory, not the embedded VM size.
